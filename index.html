Project Overview

This project demonstrates real-time facial emotion recognition directly in the browser. A convolutional neural network trained on 48×48 grayscale facial images is executed fully client-side using ONNX Runtime Web. Face detection is handled by BlazeFace, ensuring robust ROI extraction under varying lighting and pose conditions.

Technical Details

Model Architecture

  • Input: 48×48 grayscale
  • Conv(32) → BN → ReLU → MaxPool
  • Conv(64) → BN → ReLU → MaxPool
  • Conv(128) → BN → ReLU → MaxPool
  • Conv(64) → BN → ReLU → Dropout(0.4)
  • GlobalAveragePooling
  • Dense(7) → Softmax

Training Strategy

  • Balanced FER-based dataset
  • Online augmentation
  • Adam optimizer
  • Label smoothing (0.05)
  • BatchNorm regularization
  • Metric-based best model promotion

Browser Inference Pipeline

1. Face Detection

BlazeFace detects the face ROI directly in the browser.

2. Preprocessing

Crop → Resize (48×48) → Grayscale → Normalize [0,1].

3. ONNX Inference

Fully client-side execution with temporal smoothing and stability gating.
